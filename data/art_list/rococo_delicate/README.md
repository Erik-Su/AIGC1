# 洛可可精致宫廷风（rococo）艺术风格手册

本文件是 `rococo_delicate` 风格目录的唯一主文档，集中管理风格定位、资产提示词、导演分镜、质量验收和风险规避规则。生成角色、场景、道具、分镜或视频提示词时，优先读取本文件，不再拆分查找多个子文档。

## 1. 商用定位

| 维度 | 内容 |
|---|---|
| 中文名称 | 洛可可精致宫廷风 |
| 英文通用词 | rococo |
| 风格分类 | 经典艺术 |
| 适用内容 | 轻喜剧宫廷、甜美贵族、精致室内 |
| 情绪基调 | 轻盈、繁复、甜美、优雅 |
| 媒介基础 | 装饰性古典绘画 |
| 线条系统 | 柔软曲线、涡卷装饰、细腻服饰线 |
| 材质系统 | 蕾丝、瓷器、丝绸、镀金边、花卉纹样 |
| 光影系统 | 柔粉室内光、奶油色反射、低对比阴影 |
| 色彩系统 | 粉蓝、奶油白、玫瑰粉、浅金、薄荷绿 |
| 主题元素 | 沙龙、花园亭、茶具、扇子、花篮、镜子 |

### 适合使用

- 需要稳定批量产出同一世界观下的角色、场景、道具和连续镜头。
- 需要把通用艺术风格转化为可执行的 AI 漫剧资产规范。
- 需要在不引用具体人名、公司名、品牌名、作品名和角色名的前提下，获得清晰可控的画面风格。

### 不适合使用

- 只想临摹某个已知作品、角色、品牌视觉或画师个人风格。
- 需要完全写实新闻摄影、纯产品渲染或不带叙事属性的素材图。
- 缺少角色身份、场景用途、道具功能和镜头目标的空泛提示词。

## 2. 风格视觉 DNA

| 模块 | 商用控制要求 |
|---|---|
| 轮廓 | 保持“柔软曲线、涡卷装饰、细腻服饰线”的可识别边界；角色和道具缩小后仍能读清剪影。 |
| 结构 | 人物比例、服装层级、道具尺寸和场景透视必须服务连续镜头复用。 |
| 材质 | 以“蕾丝、瓷器、丝绸、镀金边、花卉纹样”作为主材质系统，材质描述要落到表面、边缘、磨损和反射。 |
| 色彩 | 使用“粉蓝、奶油白、玫瑰粉、浅金、薄荷绿”建立主色、辅助色和点缀色；单张图不超过 5 个核心色。 |
| 光影 | 以“柔粉室内光、奶油色反射、低对比阴影”统一角色、场景和道具，不允许同一镜头内光源方向互相矛盾。 |
| 情绪 | 画面应呈现“轻盈、繁复、甜美、优雅”，避免只堆砌装饰而没有叙事功能。 |

## 4. 角色资产规范

### 角色底模

角色底模用于主角、配角和常驻群像。商用生产中必须固定脸型、五官比例、发型外轮廓、体型、主色、服装剪裁和一个原创识别点。

```text
原创漫剧角色设定图，洛可可精致宫廷风，rococo，身份{身份}，年龄{年龄段}，性格{性格}，体型{比例与姿态}，脸型{脸型}，眉眼{眉眼距离与神态}，发型{长度/轮廓/发色}，服装{上装/下装/鞋履/外套/配饰}，柔软曲线、涡卷装饰、细腻服饰线，蕾丝、瓷器、丝绸、镀金边、花卉纹样，柔粉室内光、奶油色反射、低对比阴影，粉蓝、奶油白、玫瑰粉、浅金、薄荷绿，正面全身、三分之二侧面、背面、表情小窗，干净背景，角色完整入镜。
```

### 角色衍生

衍生图只能改变情绪、服装状态、动作、年龄阶段或镜头景别，不能改变身份识别。

```text
保持同一原创角色，固定脸型、五官比例、发型外轮廓、体型、主色和原创识别点，生成{衍生状态}，洛可可精致宫廷风，装饰性古典绘画，柔软曲线、涡卷装饰、细腻服饰线，蕾丝、瓷器、丝绸、镀金边、花卉纹样，柔粉室内光、奶油色反射、低对比阴影，镜头{全身/半身/特写}，情绪{情绪}，动作{动作}，服装状态{干净/雨湿/破损/礼服/训练装/旅装}，连续性一致。
```

### 角色验收

| 检查项 | 商用标准 |
|---|---|
| 身份一致 | 多张图能看出是同一原创角色。 |
| 造型稳定 | 发型、体型、服装剪裁和主色不漂移。 |
| 表情可演 | 至少能扩展出平静、紧张、愤怒、惊讶、悲伤、微笑六种状态。 |
| 动作可拍 | 手部、脚部和服装结构能支持行走、转身、奔跑、坐下和拿取道具。 |

## 5. 场景资产规范

场景必须支持角色走位和镜头调度，不只是背景图。每个场景都要写清前景、中景、后景、主光方向、角色行动区和关键道具位置。

```text
原创漫剧场景设定图，{场景名称}，洛可可精致宫廷风，装饰性古典绘画，前景{框景/遮挡/叙事物}，中景{角色行动区}，后景{空间延展}，主题元素：沙龙、花园亭、茶具、扇子、花篮、镜子，材质：蕾丝、瓷器、丝绸、镀金边、花卉纹样，光影：柔粉室内光、奶油色反射、低对比阴影，色彩：粉蓝、奶油白、玫瑰粉、浅金、薄荷绿，镜头{广角/标准/长焦}，空间透视清楚，可供角色行走与表演，无文字无标志。
```

### 场景衍生

```text
保持同一原创场景，固定建筑结构、空间动线、主要入口、关键道具位置和主光方向，生成{清晨/黄昏/雨天/夜晚/冲突后/节庆}版本，洛可可精致宫廷风，蕾丝、瓷器、丝绸、镀金边、花卉纹样，柔粉室内光、奶油色反射、低对比阴影，前景变化{元素}，中景变化{元素}，后景变化{元素}，同一世界观连续一致。
```

### 场景验收

- 角色行动区不能被装饰物堵死。
- 远中近层级清楚，缩略图也能读出空间关系。
- 光源方向、阴影落点和反射逻辑前后一致。
- 同一地点的时间、天气和剧情状态变化必须保留空间骨架。

## 6. 道具资产规范

道具必须有叙事功能、尺度、材质、状态和可追踪细节。商业项目中，道具常用于推动剧情、制造悬念、证明身份或承接镜头连续性。

```text
原创漫剧道具设定图，{道具名称}，叙事功能{功能}，使用者{角色身份}，洛可可精致宫廷风，装饰性古典绘画，材质：蕾丝、瓷器、丝绸、镀金边、花卉纹样，光影：柔粉室内光、奶油色反射、低对比阴影，主色{颜色}，辅助色{颜色}，状态{全新/旧化/战损/封存/觉醒/修复}，正面、侧面、背面、俯视图、关键细节放大，独立静物展示，干净背景，无文字无标志。
```

### 道具状态表

| 状态 | 画面要求 |
|---|---|
| 初始 | 结构完整，材质清楚，功能一眼可懂。 |
| 使用中 | 增加手汗、灰尘、轻微划痕、边缘磨损。 |
| 战损 | 裂纹、缺口、烧灼、变形要有方向和原因。 |
| 修复 | 新旧材料交界、补丁、铆钉、缝合或加固结构清楚。 |
| 觉醒 | 发光或异常效果必须来自结构缝隙、纹理或内部能量点。 |

## 7. 分镜与视频规范

分镜提示词必须写清景别、机位、运镜、时长、动作、情绪、道具位置和连续性。不要把多个动作塞进一个镜头。

### 单镜头公式

```text
洛可可精致宫廷风，{景别}，{机位}，{镜头运动}，时长{秒数}秒，{角色}在{场景}中{动作}，使用或看向{道具}，情绪{情绪}，柔粉室内光、奶油色反射、低对比阴影，蕾丝、瓷器、丝绸、镀金边、花卉纹样，保持角色面容、服装、道具位置和场景空间连续一致，无文字无标志。
```

### 三镜头段落

| 镜头 | 作用 | 推荐写法 |
|---|---|---|
| S01 建立镜头 | 交代地点、时间、天气和人物位置。 | 远景或大全景，固定或缓慢推近。 |
| S02 行动镜头 | 推动事件，让角色和道具产生关系。 | 中景、过肩、横移、跟拍或低机位。 |
| S03 情绪镜头 | 展示反应、选择或悬念。 | 近景、特写、固定镜头或缓慢推近。 |

| 镜头 | 景别 | 机位 | 运镜 | 时长 | 画面内容 | 角色状态 | 场景/道具 | 光影色彩 | 连续性 |
|---|---|---|---|---|---|---|---|---|---|

## 9. 风险词改写规则

| 风险输入 | 安全改写 |
|---|---|
| 想要某知名作品的感觉 | 改为“经典艺术题材 + 装饰性古典绘画 + 轻盈、繁复、甜美、优雅”。 |
| 想要某画师的画风 | 改为“柔软曲线、涡卷装饰、细腻服饰线 + 蕾丝、瓷器、丝绸、镀金边、花卉纹样 + 柔粉室内光、奶油色反射、低对比阴影”。 |
| 想要某品牌质感 | 改为具体材质、工艺、色彩和镜头，例如“蕾丝、瓷器、丝绸、镀金边、花卉纹样”。 |
| 想要某角色服装 | 改为服装结构、功能、材质、色彩和原创识别点。 |
| 想要某平台界面 | 改为“无标识信息面板”“抽象屏幕”“通用交互界面”。 |

## 10. 使用边界

- 只使用通用艺术流派、媒介质感、题材类型、地域文化、时代语汇和镜头语言。
- 不使用具体人名、公司名、品牌名、平台名、作品名、角色名或可识别 IP 标志。
- 若输入含风险名称，先抽象为媒介、色彩、材质、构图、情绪和时代描述，再进入提示词。
- 最多叠加 3 个风格词：主风格 1 个、媒介或质感 1 个、光影或情绪 1 个。
