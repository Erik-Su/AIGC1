# 叙事手法 · 喜剧幽默 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `喜剧幽默` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 预期管理、误会递进、角色认真性、反应节拍 |
| 离场感受 | 开怀、释然、会心一笑，允许笑中带一点真实刺痛 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 先建立规则，再让规则失灵 | 开场必须让观众理解人物以为世界如何运转，笑点才有预期差。 | 需要落到人物行动、场景规则或镜头节奏 |
| 人物越认真，荒唐越成立 | 角色不能为了搞笑而自知搞笑；他要把荒唐目标当成真实任务执行。 | 需要落到人物行动、场景规则或镜头节奏 |
| 笑点必须推动关系或剧情 | 每个包袱后都要改变信息、关系、处境或人物自尊，避免孤立段子堆砌。 | 需要落到人物行动、场景规则或镜头节奏 |
| 善意是商业喜剧底线 | 可以嘲笑执念、误解和失败，避免把弱势身份、疾病、伤害或羞辱当作笑料。 | 需要落到人物行动、场景规则或镜头节奏 |
| 反应镜头决定笑点落地 | 包袱后必须给当事人或旁观者一个可读反应，让观众确认情绪方向。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 正常秩序 | 建立正式场合、人物执念或社会规则 | 干净、正经、略有不对劲 | 埋一个可回收的小物件或小谎言 |
| 小偏差 | 一个无伤大雅的错误打乱计划 | 尴尬但可补救 | 让角色选择掩盖而不是坦白 |
| 误会链 | 不同角色掌握不同信息并各自行动 | 节奏加快、信息错位 | 观众知道得比角色多半步 |
| 集体失控 | 所有掩盖动作在公开场合同时爆发 | 混乱、反差、节奏高点 | 保持空间关系清楚，避免只剩吵闹 |
| 真心暴露 | 荒唐行为背后的真实需求被看见 | 笑意收住、情感露出 | 用沉默或小动作承接，不急着解释 |
| 回环收束 | 最初的小物件或小谎言反向发挥作用 | 轻松、释然、余味 | 最后一个小包袱不能推翻人物成长 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 正式仪式出错 | 主持、婚礼、汇报、颁奖等庄重秩序被小错误侵入 | 秩序与狼狈同框 | 不要用嘲讽旁白解释笑点 |
| 身份错位 | 角色被误认成不该承担的身份 | 认真扮演和不断露馅 | 误认必须有合理触发点 |
| 隐瞒补救 | 角色为保全面子不断扩大谎言 | 越补越乱 | 每次补救都要制造新问题 |
| 多人各说各话 | 每个人都以为自己理解真相 | 视线和台词互相打架 | 观众的信息边界要清楚 |
| 荒唐中的真情 | 一个滑稽动作突然暴露在乎 | 笑点转为温度 | 不能把情感段落拍成硬煽情 |
| 冷静旁观 | 镜头不急，等待人物自己走进困境 | 荒诞自然发生 | 避免用过度剪辑替代喜剧节拍 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 正式配乐反衬 | 荒唐行为发生时音乐仍保持庄重，制造反差。 | 声音必须有可辨声源，不用抽象气氛词 |
| 环境声抽空 | 包袱前短暂降低环境声，突出呼吸、衣料、脚步等小声响。 | 声音必须有可辨声源，不用抽象气氛词 |
| 错拍音效 | 音效只服务节拍，不用卡通化声音破坏人物真实。 | 声音必须有可辨声源，不用抽象气氛词 |
| 旁观者声音 | 忍笑、轻咳、椅子移动可作为笑点余波。 | 声音必须有可辨声源，不用抽象气氛词 |
| 沉默 | 真情暴露时撤掉配乐，让动作本身承担情绪。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 全景 | 显示角色看不到的空间异常或即将发生的尴尬。 | 景别选择要说明叙事理由 |
| 中景 | 承载对话、肢体动作、错位站位，是喜剧主力景别。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉角色努力维持体面的表情崩裂。 | 景别选择要说明叙事理由 |
| 特写 | 给错拿的物件、写错的信息、停住的手一个明确落点。 | 景别选择要说明叙事理由 |
| 群像同框 | 让反应链在同一画面里扩散，形成二次笑点。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 固定机位 | 作为默认喜剧观察视角，让荒唐行为自己发生。 | 运镜必须服务信息释放或人物状态变化 |
| 缓慢推近 | 用于观众逐渐发现细节的笑点，不提前泄露。 | 运镜必须服务信息释放或人物状态变化 |
| 快速转向 | 用于突然揭示旁观者或反向信息，必须有明确视线动因。 | 运镜必须服务信息释放或人物状态变化 |
| 轻快跟拍 | 用于追赶、躲藏、抢救，但要保持动作因果。 | 运镜必须服务信息释放或人物状态变化 |
| 停留不切 | 笑点后停半拍，允许尴尬在空气中扩散。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 只有台词段子，没有人物目标和处境推进。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 角色为了搞笑主动降智，破坏可信度。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 笑点依赖羞辱、歧视、身体伤害或现实弱势处境。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 铺垫不足导致观众不知道规则被怎样打破。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 包袱后没有反应镜头，笑点落不住。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉风格替代叙事判断，把画面做可爱但故事不可演。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `喜剧幽默` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `喜剧幽默` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
