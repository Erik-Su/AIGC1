# 分镜表叙事手法 · 喜剧幽默 · 商用执行手册

## 一、分镜表定位

分镜表是把 `喜剧幽默` 的叙事策略翻译成镜头执行的生产文件。它不只是镜头清单，而是控制观众信息、人物行动、节奏停顿、声音进入和场景转场的导演工具。每个镜头都必须说明自己承担的叙事功能，不能只写“好看”“氛围”“高级”“震撼”。

| 维度 | 分镜表要求 |
|---|---|
| 类型核心 | 预期管理、误会递进、角色认真性、反应节拍 |
| 观众体验 | 开怀、释然、会心一笑，允许笑中带一点真实刺痛 |
| 核心任务 | 把主题、段落、人物选择和信息释放拆成可拍镜头 |
| 组合方式 | 先执行本叙事手册，再叠加任意 `art_list` 视觉风格 |

## 二、推荐字段

| 字段 | 用途 | 填写要求 |
|---|---|---|
| 分镜号 | 镜头顺序和段落层级 | 支持按场次、段落、镜头三级编号 |
| 叙事功能 | 说明镜头负责铺垫、误导、揭示、转折、反应、余波或关系变化 | 禁止只写“氛围镜头” |
| 观众信息 | 标明观众此刻知道什么 | 控制悬念、笑点、恐惧、心动或燃点 |
| 角色信息 | 标明角色此刻知道什么 | 用于制造信息差或认知错位 |
| 景别/机位/运镜 | 把故事意图转成镜头语言 | 必须说明叙事理由 |
| 时长 | 控制节奏、停顿和信息吸收 | 使用秒数区间或节奏说明 |
| 人物行动 | 写连续物理动作链 | 避免只写情绪形容词 |
| 台词/留白 | 标明要说的信息和必须保留的沉默 | 台词不解释画面已经成立的信息 |
| 声音/音乐 | 环境声、动作声、音乐、静默如何参与叙事 | 具体到声源 |
| 转场 | 说明场景之间的因果、情绪或视觉连接 | 不使用无意义硬切 |

## 三、景别选择规则

| 景别/构图 | 叙事用途 | 分镜写法 |
|---|---|---|
| 全景 | 显示角色看不到的空间异常或即将发生的尴尬。 | 写入分镜表时标明叙事功能 |
| 中景 | 承载对话、肢体动作、错位站位，是喜剧主力景别。 | 写入分镜表时标明叙事功能 |
| 近景 | 捕捉角色努力维持体面的表情崩裂。 | 写入分镜表时标明叙事功能 |
| 特写 | 给错拿的物件、写错的信息、停住的手一个明确落点。 | 写入分镜表时标明叙事功能 |
| 群像同框 | 让反应链在同一画面里扩散，形成二次笑点。 | 写入分镜表时标明叙事功能 |

### 景别执行原则

- 景别选择必须回答“观众此刻应该看见什么”：空间规则、人物关系、行动结果、情绪反应还是叙事证据。
- 同一场戏内景别变化要有方向，例如从远到近表示压力靠近，从近到远表示抽离或失去。
- 特写只给真正承担信息的物件、身体反应或关系证据；不要把所有漂亮细节都写成特写。
- 群像或多人场景必须标明主次关系，避免画面中所有角色同时抢戏。

## 四、运镜节奏规则

| 运镜 | 叙事用途 | 分镜写法 |
|---|---|---|
| 固定机位 | 作为默认喜剧观察视角，让荒唐行为自己发生。 | 写明触发点和结束点 |
| 缓慢推近 | 用于观众逐渐发现细节的笑点，不提前泄露。 | 写明触发点和结束点 |
| 快速转向 | 用于突然揭示旁观者或反向信息，必须有明确视线动因。 | 写明触发点和结束点 |
| 轻快跟拍 | 用于追赶、躲藏、抢救，但要保持动作因果。 | 写明触发点和结束点 |
| 停留不切 | 笑点后停半拍，允许尴尬在空气中扩散。 | 写明触发点和结束点 |

### 运镜执行原则

- 运镜开始点和结束点都要写清楚，例如“从门口缓推到角色握紧的手”，不能只写“镜头缓推”。
- 运镜速度服务信息释放：发现型可慢，危机型可快，决断型要稳。
- 快切段落要插入确认镜头，让观众知道位置、结果和代价。
- 关键反应、沉默、选择、揭示、和解、失败通常要减少花哨运镜。

## 五、时长把控

| 镜头类型 | 建议时长 | 叙事目的 |
|---|---|---|
| 铺垫镜头 | 2-4 秒 | 让观众看懂场景规则和人物意图。 |
| 包袱镜头 | 1-2 秒 | 落点要突然，动作完成后立即切反应或停住。 |
| 反应镜头 | 1.5-3 秒 | 给尴尬、石化、忍笑或错愕足够时间。 |
| 重复笑点 | 三次递进 | 第一遍建模，第二遍强化，第三遍打破或反向使用。 |
| 真情停顿 | 3-5 秒 | 让笑意自然降下来，避免马上追加段子。 |

### 时长执行原则

- 时长不是固定公式，最终以观众能否读懂信息和感到情绪变化为准。
- 铺垫镜头必须让规则成立；落点镜头必须干净；反应和余波镜头必须让情绪被接住。
- 对白场景中，每次切换都应改变信息或关系；如果只是重复观点，应合并镜头。
- 无台词镜头需要更明确的身体动作、声源或空间变化，否则容易变成空镜堆砌。

## 六、人物行为与表演调度

| 编号 | 行为原则 | 分镜落点 |
|---|---|---|
| 1 | 先建立规则，再让规则失灵 | 开场必须让观众理解人物以为世界如何运转，笑点才有预期差。 |
| 2 | 人物越认真，荒唐越成立 | 角色不能为了搞笑而自知搞笑；他要把荒唐目标当成真实任务执行。 |
| 3 | 笑点必须推动关系或剧情 | 每个包袱后都要改变信息、关系、处境或人物自尊，避免孤立段子堆砌。 |
| 4 | 善意是商业喜剧底线 | 可以嘲笑执念、误解和失败，避免把弱势身份、疾病、伤害或羞辱当作笑料。 |
| 5 | 反应镜头决定笑点落地 | 包袱后必须给当事人或旁观者一个可读反应，让观众确认情绪方向。 |

### 行为写法

- 用连续物理动作链替代抽象情绪：写“停在门口→手指松开门把→把话吞回去”，不要只写“很难过”。
- 每个动作都应带有目的：遮掩、靠近、试探、确认、逃避、承担、保护、放手。
- 人物反应要分层：当事人、旁观者、对立者和环境都可以有不同反应。
- 动作结果要可见，例如物件位置改变、关系距离改变、空间通路改变或声音状态改变。

## 七、台词、留白与声音

| 声音策略 | 叙事用途 | 分镜写法 |
|---|---|---|
| 正式配乐反衬 | 荒唐行为发生时音乐仍保持庄重，制造反差。 | 写明声源、进入时机和退出时机 |
| 环境声抽空 | 包袱前短暂降低环境声，突出呼吸、衣料、脚步等小声响。 | 写明声源、进入时机和退出时机 |
| 错拍音效 | 音效只服务节拍，不用卡通化声音破坏人物真实。 | 写明声源、进入时机和退出时机 |
| 旁观者声音 | 忍笑、轻咳、椅子移动可作为笑点余波。 | 写明声源、进入时机和退出时机 |
| 沉默 | 真情暴露时撤掉配乐，让动作本身承担情绪。 | 写明声源、进入时机和退出时机 |

### 台词与留白

- 台词负责无法被画面直接看见的信息；画面已经成立的内容不要再让角色解释一遍。
- 留白必须有承接动作，例如看向别处、停止动作、声音消失、对方没有回应。
- 声音可以先于画面进入，也可以在关键时刻撤离；进入和撤离都要写入分镜表。
- 环境声、动作声、呼吸声和沉默应与配乐一样被规划，而不是后期随意补充。

## 八、转场设计

| 转场方式 | 使用方法 | 适用场景 |
|---|---|---|
| 动作接动作 | 用上一场未完成的动作进入下一场 | 适合保持因果连续 |
| 声音预入 | 下一场声音先进入当前画面 | 适合制造预兆、反差或时间跳转 |
| 物件回环 | 同一物件在不同段落改变意义 | 适合形成商业记忆点 |
| 空间对照 | 相似构图呈现关系或权力变化 | 适合表现成长、失去、和解或反转 |
| 情绪断切 | 从高压切到安静或从日常切到危机 | 必须让观众理解时间和地点变化 |

## 九、常见失败模式与修正

| 编号 | 失败模式 | 分镜修正方向 |
|---|---|---|
| 1 | 只有台词段子，没有人物目标和处境推进。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 2 | 角色为了搞笑主动降智，破坏可信度。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 3 | 笑点依赖羞辱、歧视、身体伤害或现实弱势处境。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 4 | 铺垫不足导致观众不知道规则被怎样打破。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 5 | 包袱后没有反应镜头，笑点落不住。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 6 | 视觉风格替代叙事判断，把画面做可爱但故事不可演。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |

## 十、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 可读性 | 只看分镜表也能理解人物目标、阻碍、信息差和状态变化。 |
| 可执行性 | 每个镜头都有景别、行动、时长、声音或转场依据。 |
| 类型性 | 镜头策略体现 `喜剧幽默`，而不是换标题仍可用于任意类型。 |
| 节奏 | 铺垫、转折、反应和余波均有明确时长或停顿规则。 |
| 人物 | 行为链具体，可由演员或生成模型执行。 |
| 边界 | 不引用具体 IP、导演、作品、品牌、平台或真实人物。 |
| 安全 | 不提供现实伤害、违法或危险行为的可操作步骤。 |
| 组合 | 可与任何视觉风格叠加，且不把美术风格写成叙事风格。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `喜剧幽默` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
