# 叙事手法 · 仙侠玄幻 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `仙侠玄幻` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 本心与执念、因果誓约、境界试炼、天地回应 |
| 离场感受 | 荡气回肠、因果已偿，本心在宏大规则中被确认 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 修行是内心选择的外化 | 境界提升不能只是变强，要回应执念、恐惧、亏欠或誓言。 | 需要落到人物行动、场景规则或镜头节奏 |
| 奇观必须绑定因果 | 秘境、天象、法术、灵兽都要推动人物考验或规则揭示。 | 需要落到人物行动、场景规则或镜头节奏 |
| 情义与大道冲突 | 仙侠张力来自私人情义和天地规则之间的取舍。 | 需要落到人物行动、场景规则或镜头节奏 |
| 法术体现人物性格 | 同样的力量因修行路径、价值观和代价不同而不同。 | 需要落到人物行动、场景规则或镜头节奏 |
| 终局回应誓约 | 决战不只击败强敌，还要偿还因果、破除心魔或重建秩序。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 凡尘牵挂 | 用具体人和事建立入道前的情感根 | 朴素、可亲 | 不要开场只堆世界观 |
| 入门试炼 | 山门、师承、规则和缺口出现 | 敬畏、压力 | 试炼暴露主角弱点 |
| 秘境因果 | 奇幻空间让欲望、恐惧或信任被测试 | 神秘、危险 | 奇观必须改变关系 |
| 心魔显形 | 主角面对执念或亏欠 | 压迫、内省 | 心魔不是普通幻觉，要有道德命题 |
| 大义抉择 | 情义与天规、个人与众生发生冲突 | 高压、悲壮 | 选择要有不可逆代价 |
| 天地回应 | 人物本心确定后，外部世界产生呼应 | 宏大、释放 | 回应是结果，不是无因开挂 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 山门初见 | 人物尺度与宗门秩序对比 | 敬畏、陌生 | 用空间层级表达境界 |
| 师徒授诀 | 传承动作和规训同时发生 | 克制、信任 | 不能只讲设定 |
| 秘境寻物 | 目标物引出欲望和代价 | 奇异、试炼 | 路线和规则清楚 |
| 论道对峙 | 不同修行观念冲突 | 礼法下的锋芒 | 用行为和站位承载观点 |
| 心魔幻境 | 空间错位表现内在冲突 | 迷惘、压迫 | 保留现实锚点 |
| 渡劫/守护 | 个人突破与守护对象同步 | 痛感、宏大 | 天象服务本心选择 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 自然灵气声 | 风、铃、远钟、水声、剑鸣构成修行空间。 | 声音必须有可辨声源，不用抽象气氛词 |
| 法术声源 | 力量来自符、剑、阵、雷、经文等可辨源头。 | 声音必须有可辨声源，不用抽象气氛词 |
| 心魔回声 | 重复誓言、旧话或呼吸，制造内在压迫。 | 声音必须有可辨声源，不用抽象气氛词 |
| 情义克制 | 静态关系段不要满配乐，保留衣袖、烛火、雨声。 | 声音必须有可辨声源，不用抽象气氛词 |
| 天地主题 | 终局旋律从个人动机扩展为宏观回应。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 大远景 | 云海、山门、秘境、天象与人物尺度。 | 景别选择要说明叙事理由 |
| 中景 | 师徒、同门、对手之间的礼法距离。 | 景别选择要说明叙事理由 |
| 近景 | 执念、顿悟、压抑情感和心魔侵扰。 | 景别选择要说明叙事理由 |
| 特写 | 灵印、剑穗、丹药、符纹、手势等因果物件。 | 景别选择要说明叙事理由 |
| 层级构图 | 台阶、阵法、门槛、云桥表现境界差异。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 缓慢升降 | 表现境界、山门、天象的尺度变化。 | 运镜必须服务信息释放或人物状态变化 |
| 稳定环绕 | 用于阵法、悟道、誓约，不可过度炫技。 | 运镜必须服务信息释放或人物状态变化 |
| 跟随剑势 | 法术动作保持方向和起落。 | 运镜必须服务信息释放或人物状态变化 |
| 反常移动 | 心魔段表现空间失序。 | 运镜必须服务信息释放或人物状态变化 |
| 由内到外 | 突破时从眼神、手势扩展到天地。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 只堆仙山法术，没有本心、因果和誓约。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 境界提升无代价，像无因开挂。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 奇观场景不改变人物关系或规则理解。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 法术对抗方向混乱，观众看不清力量来源。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 心魔只是视觉幻觉，没有道德选择。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉仙侠但导演叙事缺少修行路径和天地回应。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `仙侠玄幻` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `仙侠玄幻` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
