# 导演叙事手法技能包库

本目录存放导演叙事手法技能包。导演手册负责 **故事讲述**：主题、结构、信息释放、人物行动、节奏、声音、分镜和转场。视觉风格与导演风格相对独立，视觉呈现请再叠加 `data/skills/art_list` 中的艺术风格手册。

## 目录

| 目录 | 中文名称 | 定位 |
|---|---|---|
| `Comedy_humor` | 喜剧幽默 | 适用于任何视觉风格，通过误会、反差、节奏错位与人物执念制造轻松、机智、可共情的叙事喜感。 |
| `Coming_of_age` | 成长青春 | 适用于任何视觉风格，通过选择、失落、友谊、自我认同与第一次告别，讲述人物从被世界定义到主动定义自己的过程。 |
| `Family_warmth` | 家庭温情 | 适用于任何视觉风格，通过日常照料、代际误解、隐忍表达与关系修复，讲述亲密关系中笨拙却持久的爱。 |
| `Urban_workplace_drama` | 都市职场剧 | 适用于任何视觉风格，通过职业压力、利益博弈、团队协作与个人边界，讲述现代城市中人在工作与自我之间的选择。 |
| `Historical_epic` | 历史史诗 | 适用于任何视觉风格，以时代洪流、群体命运与个人抉择构建宏大叙事。 |
| `Horror_supernatural` | 超自然恐怖 | 适用于任何视觉风格，以未知力量、禁忌规则和逐步失控的感知制造恐惧。 |
| `Mystery_thriller` | 悬疑惊悚 | 适用于任何视觉风格，以线索、误导、倒计时和真相重构推动紧张叙事。 |
| `Psychological_drama` | 心理剧情 | 适用于任何视觉风格，以内在冲突、关系张力和情绪转变驱动人物叙事。 |
| `Hot_blooded_action` | 热血动作 | 适用于任何视觉风格的高能叙事流派，核心在于用目标、对抗、牺牲与爆发推动角色在行动中完成精神跃迁。 |
| `Scifi_post_apocalypse` | 科幻后末日 | 适用于任何视觉风格的科幻后末日叙事流派，核心在于通过废墟秩序、生存选择与未来希望，讲述人在崩坏世界中如何重新定义文明。 |
| `Sweet_romance_novel` | 甜宠言情 | 适用于任何视觉风格的甜宠言情叙事流派，核心在于用细腻互动、情绪递进与关系确认，讲述两个人如何在日常与误会中逐步靠近。 |
| `Xianxia_fantasy` | 仙侠玄幻 | 适用于任何视觉风格的仙侠玄幻叙事流派，核心在于用修行、因果、抉择与天地秩序，讲述人物如何在力量增长中守住本心。 |

## 统一结构

每个子目录包含：

- `README.md`：技能包总说明。
- `director_manual/director_planning_narrative.md`：叙事规划阶段的导演手法。
- `director_manual/director_storyboard_table_narrative.md`：分镜表阶段的导演手法。
- `images/director_concept.png`：1920 × 1080 横版概念图，用于表达该叙事流派的故事气质。

## 使用原则

- 先选叙事流派，再选视觉风格。
- 叙事流派决定故事如何讲；视觉风格决定画面如何呈现。
- 不引用具体导演、画师、演员、公司、品牌、平台、作品、角色或可识别 IP。
- 不把 `art_list` 的材质、色彩、线条误写成导演叙事风格。
