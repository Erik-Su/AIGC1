# 叙事手法 · 悬疑惊悚 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `悬疑惊悚` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 线索公平、认知错位、压力升级、真相重排 |
| 离场感受 | 紧张释放后回想前文细节，觉得真相早已埋好 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 线索要公平但不显眼 | 观众回看能发现真相依据，初看不会被硬提示。 | 需要落到人物行动、场景规则或镜头节奏 |
| 误导来自人物判断 | 不要用导演作弊隐藏关键信息，而让角色合理误解。 | 需要落到人物行动、场景规则或镜头节奏 |
| 惊悚来自时间压力 | 倒计时、追踪、封锁、证据消失让调查带紧迫感。 | 需要落到人物行动、场景规则或镜头节奏 |
| 信息边界要清楚 | 每场戏明确观众、主角、对手分别知道什么。 | 需要落到人物行动、场景规则或镜头节奏 |
| 真相要重排意义 | 揭示不是新增设定，而是让前文行为获得新解释。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 异常事件 | 一个不合理结果打破日常逻辑 | 疑问、警觉 | 提出核心问题 |
| 初步调查 | 线索指向看似明确的解释 | 推进、建立假设 | 埋入可回收细节 |
| 误导加深 | 证据和证言支持错误方向 | 紧张、怀疑 | 误导要有真实动机 |
| 压力收紧 | 时间、空间或对手行动压迫主角 | 惊悚、迫近 | 避免只靠音乐制造紧张 |
| 关键重排 | 一个细节改写全部因果 | 震动、清晰 | 揭示要回扣前文 |
| 余波确认 | 真相带来代价或新威胁 | 释放、后怕 | 不要用长解释替代视觉回收 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 案发/异常现场 | 用空间和物件提出问题 | 秩序被打破 | 现场逻辑要可复盘 |
| 询问/对峙 | 证言中的停顿、闪躲、过度具体成为线索 | 不信任 | 不要让角色直接说破 |
| 跟踪/窥视 | 主角或观众处于受限视角 | 被看见与看不见 | 方位必须清楚 |
| 资料检索 | 屏幕、文件、录音、旧照片提供证据 | 冷静中紧张 | 镜头停留到观众能读懂 |
| 密闭压力 | 电梯、车厢、走廊、地下室收窄选择 | 无法逃避 | 不要滥用黑暗遮信息 |
| 真相回收 | 前文物件或动作以新意义出现 | 恍然、冲击 | 避免口播复盘过长 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 细节声 | 钥匙、录音杂音、脚步节奏可成为线索。 | 声音必须有可辨声源，不用抽象气氛词 |
| 低频压力 | 用于时间迫近，不可全程铺满。 | 声音必须有可辨声源，不用抽象气氛词 |
| 空间回声 | 走廊、地下室、空房间增强被跟踪感。 | 声音必须有可辨声源，不用抽象气氛词 |
| 信息声源 | 电话、广播、监控音频要清楚可辨。 | 声音必须有可辨声源，不用抽象气氛词 |
| 揭示静默 | 真相出现时撤掉噪声，让认知落地。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 定场全景 | 保存可复盘的空间证据。 | 景别选择要说明叙事理由 |
| 中近景 | 观察证言、试探、隐瞒和心理防线。 | 景别选择要说明叙事理由 |
| 物件特写 | 线索出现时不加过度戏剧化。 | 景别选择要说明叙事理由 |
| 窥视构图 | 门缝、玻璃、监控、反射用于受限信息。 | 景别选择要说明叙事理由 |
| 空镜 | 让缺席、被移动的物件或空间变化说话。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 缓慢扫描 | 引导观众检查现场。 | 运镜必须服务信息释放或人物状态变化 |
| 受限跟拍 | 让观众和主角共享不完整视野。 | 运镜必须服务信息释放或人物状态变化 |
| 突然停顿 | 用于角色意识到某个逻辑漏洞。 | 运镜必须服务信息释放或人物状态变化 |
| 交叉剪辑 | 并置追踪者和被追踪者，但不提前作弊泄露。 | 运镜必须服务信息释放或人物状态变化 |
| 回收镜头 | 重复前文构图但改变意义。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 真相依赖导演隐藏关键信息，回看不公平。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 线索太显眼，观众提前失去悬疑。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 误导没有人物动机，只是随便骗观众。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 惊悚靠持续噪音和黑暗，缺少压力结构。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 揭示用长对白解释，没有镜头回收。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉紧张但信息边界不清，无法复盘。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `悬疑惊悚` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `悬疑惊悚` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
