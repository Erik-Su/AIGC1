# 叙事手法 · 家庭温情 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `家庭温情` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 日常神圣、笨拙关心、代际回响、克制和解 |
| 离场感受 | 温暖、想家、眼眶发热，但不被强行催泪 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 爱通过行动出现 | 家庭情感优先用端饭、留灯、补衣、等门、夹菜等行为表达。 | 需要落到人物行动、场景规则或镜头节奏 |
| 日常重复就是结构 | 同一动作在开头、中段、结尾重复变化，形成关系弧线。 | 需要落到人物行动、场景规则或镜头节奏 |
| 冲突要保留双向动机 | 代际矛盾不能写成单方正确，要让双方都在保护某种东西。 | 需要落到人物行动、场景规则或镜头节奏 |
| 温情需要克制 | 不依赖大哭和煽情台词，让生活细节自己产生重量。 | 需要落到人物行动、场景规则或镜头节奏 |
| 空间承载记忆 | 餐桌、厨房、门口、车站、旧房间应记录家庭关系的变化。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 稳定日常 | 展示家中固定动线和亲密习惯 | 安稳、熟悉 | 让一个小细节稍微不协调 |
| 隐性裂缝 | 人物不说的失落、疲惫或误解浮出水面 | 克制、别扭 | 用沉默和错开的视线表现 |
| 生活事件 | 搬家、离家、病痛、失业、婚礼、升学等触发变化 | 压力进入日常 | 事件服务关系，不喧宾夺主 |
| 代际对照 | 孩子做出与父母当年相似或相反的选择 | 理解开始出现 | 通过动作回响，不靠说教 |
| 行动和解 | 一个具体照料动作替代正式道歉 | 温暖、松动 | 留出对方接收这个动作的时间 |
| 日常继续 | 同一空间恢复但人物姿态改变 | 安心、余味 | 结尾不必大团圆，但要有关系方向 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 餐桌 | 多人同框显示家庭秩序、距离和未说出口的关心 | 饭菜热气与沉默同在 | 避免把吃饭拍成静态摆拍 |
| 厨房 | 照料和负担最容易可视化 | 忙碌、熟练、疲惫 | 动作链要连续 |
| 门口/玄关 | 等待、送别、回家、犹豫进入 | 关系门槛 | 不要让台词替代站位变化 |
| 旧物整理 | 照片、衣物、工具触发代际记忆 | 时间厚度 | 旧物必须改变当下选择 |
| 车站/医院/学校外 | 家庭成员在公共空间保持克制 | 外冷内热 | 避免强行拥抱解决所有问题 |
| 夜晚家中 | 灯光和小声响放大陪伴 | 安静、真实 | 不要用满配乐淹没生活声 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 生活音优先 | 锅铲、钟表、电视、门锁、热水壶构成家庭音景。 | 声音必须有可辨声源，不用抽象气氛词 |
| 配乐低覆盖 | 关键情绪段落可无配乐，保留呼吸和环境声。 | 声音必须有可辨声源，不用抽象气氛词 |
| 重复声响 | 同一门铃、脚步或碗筷声可表现时间变化。 | 声音必须有可辨声源，不用抽象气氛词 |
| 争吵留白 | 争吵后不要立刻上音乐，先保留空间的尴尬。 | 声音必须有可辨声源，不用抽象气氛词 |
| 温暖主题 | 和解段使用简洁旋律，不做强行催泪推进。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 餐桌全景 | 显示谁照顾谁、谁沉默、谁缺席。 | 景别选择要说明叙事理由 |
| 中景 | 家庭成员在同一空间里的动作关系，是主力景别。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉忍住不说、嘴硬、眼眶发红等克制情绪。 | 景别选择要说明叙事理由 |
| 手部特写 | 夹菜、塞钱、递伞、盖被子等行动证据。 | 景别选择要说明叙事理由 |
| 远景 | 用于守望、等待、送别和家的空间尺度。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 静止机位 | 让家像稳定容器，观察人物自然进出。 | 运镜必须服务信息释放或人物状态变化 |
| 缓慢跟移 | 跟随做饭、收拾、开门等日常动线。 | 运镜必须服务信息释放或人物状态变化 |
| 缓推细节 | 让观众发现没说出口的爱。 | 运镜必须服务信息释放或人物状态变化 |
| 缓拉退出 | 用于送别或关系无法马上修复的余味。 | 运镜必须服务信息释放或人物状态变化 |
| 少切换 | 避免把家庭情绪剪得急躁，保留生活连续性。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `家庭温情` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `家庭温情` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
