# 叙事手法 · 科幻后末日 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `科幻后末日` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 生存规则、旧世界遗产、资源伦理、重建希望 |
| 离场感受 | 孤独后看见微弱希望，意识到文明不是设施而是选择 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 世界规则先于奇观 | 限电、配给、隔离、通行、信号等规则让废土可信。 | 需要落到人物行动、场景规则或镜头节奏 |
| 资源选择体现价值观 | 争夺能源、药品、种子、记忆档案时必须暴露人物伦理。 | 需要落到人物行动、场景规则或镜头节奏 |
| 旧技术是问题也是证据 | 机器、档案、AI、废弃设施要揭示过去错误和未来可能。 | 需要落到人物行动、场景规则或镜头节奏 |
| 希望要具体 | 种下一株植物、修好一盏灯、传出一段信号比空喊重建更有效。 | 需要落到人物行动、场景规则或镜头节奏 |
| 冲突安全表达 | 以封锁、追赶、谈判、交换和抉择表现危机，避免现实伤害教学。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 废土日常 | 建立角色如何获取水、电、食物、通行权 | 冷清、规律 | 让末日已经成为日常 |
| 资源缺口 | 关键资源短缺迫使角色离开安全区 | 紧迫、现实 | 目标必须可见可衡量 |
| 遗迹探索 | 旧世界设施提供线索和危险 | 未知、谨慎 | 空间路线要清楚 |
| 伦理分歧 | 团队对资源分配或真相公开产生冲突 | 撕裂、压力 | 每方都有生存理由 |
| 旧真相揭示 | 灾难原因或旧系统目的被重排 | 沉重、清醒 | 揭示改变未来选择 |
| 重建信号 | 角色做出小规模但可持续的修复 | 微光、开放 | 希望必须落到行动 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 临时聚落 | 规则、分工、交换关系可视化 | 秩序脆弱 | 不要只拍破败景观 |
| 荒原迁徙 | 人与巨大废墟的尺度差 | 孤独、目标感 | 路线和风险清楚 |
| 废弃设施 | 旧世界残留系统仍在运行 | 机械、冷静、危险 | 技术设定要服务选择 |
| 资源谈判 | 筹码、谎言、信任破裂 | 紧张、现实 | 避免单纯抢夺 |
| 信号接收 | 远方还有人或真相的证据 | 希望与警觉 | 信号内容要推动剧情 |
| 种植/修复 | 文明重建的最小动作 | 安静、温度 | 不要拍成空泛励志 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 空旷声场 | 风、远处金属回响、脚步让空间显得巨大。 | 声音必须有可辨声源，不用抽象气氛词 |
| 机械残响 | 发电机、电流、旧广播提示系统残存。 | 声音必须有可辨声源，不用抽象气氛词 |
| 信号噪声 | 断续语音或频率变化成为线索。 | 声音必须有可辨声源，不用抽象气氛词 |
| 配乐克制 | 保留孤独，不把每个希望点都拍成胜利。 | 声音必须有可辨声源，不用抽象气氛词 |
| 人声温度 | 共同体段落用低声交谈、儿童声、手工声恢复生活感。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 大远景 | 荒原、遗迹、迁徙队伍、孤立人物。 | 景别选择要说明叙事理由 |
| 全景 | 聚落规则、设施结构、封锁路线。 | 景别选择要说明叙事理由 |
| 中景 | 维修、交换、协作、守望等生存动作。 | 景别选择要说明叙事理由 |
| 特写 | 能源指示、旧照片、种子、手写记录、破损终端。 | 景别选择要说明叙事理由 |
| 开放构图 | 希望节点让通路、光源、人群关系变清晰。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 缓慢横移 | 探索废墟和设备结构。 | 运镜必须服务信息释放或人物状态变化 |
| 谨慎推进 | 进入未知空间时保持观察感。 | 运镜必须服务信息释放或人物状态变化 |
| 跟随路线 | 危机段强调逃离路径和封锁点。 | 运镜必须服务信息释放或人物状态变化 |
| 稳定揭示 | 真相出现时少切换，让信息落地。 | 运镜必须服务信息释放或人物状态变化 |
| 从个人到地平线 | 结尾表现重建可能。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 只有废墟视觉，没有清楚生存规则。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 资源争夺没有伦理选择，只剩动作冲突。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `科幻后末日` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `科幻后末日` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
