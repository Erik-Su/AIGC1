# 叙事手法 · 超自然恐怖 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `超自然恐怖` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 异常规则、等待压迫、信息差、未知余波 |
| 离场感受 | 不安、后怕、回头检查生活空间的细节 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 恐惧必须有规则 | 观众可以暂时不知道规则，但事件不能随机；重复异常要逐步形成规律。 | 需要落到人物行动、场景规则或镜头节奏 |
| 先破坏熟悉感 | 超自然恐怖最有效入口是日常空间中出现不合理细节。 | 需要落到人物行动、场景规则或镜头节奏 |
| 等待比出现更重要 | 让观众有时间检查画面、怀疑声音、预想危险。 | 需要落到人物行动、场景规则或镜头节奏 |
| 惊吓不能替代叙事 | 突发音效和突然出现只作为标点，核心是规则揭示和心理压迫。 | 需要落到人物行动、场景规则或镜头节奏 |
| 安全表达 | 恐怖可以写不安、逃离、仪式感和心理压迫，避免露骨伤害细节或现实危险教学。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 轻微异常 | 一个声音、影子、时间错位打破日常 | 疑惑、微冷 | 不解释，先让角色否认 |
| 重复验证 | 角色试图用理性解释并发现规律 | 好奇转不安 | 每次验证带来更坏结果 |
| 错误解释 | 观众和角色以为找到答案 | 短暂放松 | 设置反向证据 |
| 规则揭示 | 恐惧源与过去、罪责、禁忌或失落有关 | 寒意明确 | 揭示要改变行动方案 |
| 被迫面对 | 角色进入规则中心或仪式空间 | 高压、受限 | 危险来自选择而非追逐堆叠 |
| 余波未尽 | 表面结束后留下规则残影 | 后怕、悬置 | 完成主题闭环但保留未知边界 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 熟悉地点变形 | 家、学校、办公室、旅馆出现不合理路径或重复房间 | 日常被侵入 | 空间规则要可追踪 |
| 声音先行 | 画面未见异常但声音越界 | 看不见的存在 | 声音来源要逐步变化 |
| 背景异常 | 角色未察觉，观众先看见 | 信息差压迫 | 异常不可太抢主线 |
| 旧物证据 | 照片、录音、日记、旧玩具揭示历史 | 过去回到现在 | 证据必须改变规则理解 |
| 禁忌验证 | 角色试图确认传闻或打破规则 | 好奇变恐惧 | 避免可复制的现实危险步骤 |
| 仪式/对峙 | 面对恐惧源的核心规则 | 压迫、选择 | 不要只靠追跑解决 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 环境底噪变化 | 电流、风、管道、远处低语逐步偏离正常。 | 声音必须有可辨声源，不用抽象气氛词 |
| 重复信号 | 同一敲击、铃声或童谣成为规则提示。 | 声音必须有可辨声源，不用抽象气氛词 |
| 音乐撤离 | 异常接近时减少配乐，让角色暴露在空间里。 | 声音必须有可辨声源，不用抽象气氛词 |
| 声音越界 | 声音从不可能的位置传来，提示空间规则被破坏。 | 声音必须有可辨声源，不用抽象气氛词 |
| 惊吓克制 | 突发声只用于关键转折，不能连续滥用。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 远景 | 让人物被空间吞没，背景可藏异常。 | 景别选择要说明叙事理由 |
| 中景 | 角色探索和空间变化的主力。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉听见、意识到、想否认的瞬间。 | 景别选择要说明叙事理由 |
| 特写 | 用于旧物、门缝、手电、录音机、时钟等证据。 | 景别选择要说明叙事理由 |
| 负空间构图 | 留出异常可能出现的位置，让观众主动搜寻。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 固定等待 | 让异常在观众注视中慢慢发生。 | 运镜必须服务信息释放或人物状态变化 |
| 缓慢推进 | 表现不可避免的接近。 | 运镜必须服务信息释放或人物状态变化 |
| 受限跟拍 | 限制视野，跟角色进入未知空间。 | 运镜必须服务信息释放或人物状态变化 |
| 突然停住 | 暗示角色或环境察觉到某种存在。 | 运镜必须服务信息释放或人物状态变化 |
| 克制揭示 | 看清异常后不要马上乱切，让恐惧被确认。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 事件随机发生，没有可追踪的超自然规则。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 只靠突然音效和跳脸吓人，缺少等待与余波。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 异常过早解释清楚，神秘感被耗尽。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 恐怖点依赖露骨伤害细节或现实危险操作。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 空间关系混乱，观众不知道异常从哪里来。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 画面阴暗但叙事没有信息差和规则递进。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `超自然恐怖` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `超自然恐怖` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
