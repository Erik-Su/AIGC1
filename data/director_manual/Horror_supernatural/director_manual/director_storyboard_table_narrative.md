# 分镜表叙事手法 · 超自然恐怖 · 商用执行手册

## 一、分镜表定位

分镜表是把 `超自然恐怖` 的叙事策略翻译成镜头执行的生产文件。它不只是镜头清单，而是控制观众信息、人物行动、节奏停顿、声音进入和场景转场的导演工具。每个镜头都必须说明自己承担的叙事功能，不能只写“好看”“氛围”“高级”“震撼”。

| 维度 | 分镜表要求 |
|---|---|
| 类型核心 | 异常规则、等待压迫、信息差、未知余波 |
| 观众体验 | 不安、后怕、回头检查生活空间的细节 |
| 核心任务 | 把主题、段落、人物选择和信息释放拆成可拍镜头 |
| 组合方式 | 先执行本叙事手册，再叠加任意 `art_list` 视觉风格 |

## 二、推荐字段

| 字段 | 用途 | 填写要求 |
|---|---|---|
| 分镜号 | 镜头顺序和段落层级 | 支持按场次、段落、镜头三级编号 |
| 叙事功能 | 说明镜头负责铺垫、误导、揭示、转折、反应、余波或关系变化 | 禁止只写“氛围镜头” |
| 观众信息 | 标明观众此刻知道什么 | 控制悬念、笑点、恐惧、心动或燃点 |
| 角色信息 | 标明角色此刻知道什么 | 用于制造信息差或认知错位 |
| 景别/机位/运镜 | 把故事意图转成镜头语言 | 必须说明叙事理由 |
| 时长 | 控制节奏、停顿和信息吸收 | 使用秒数区间或节奏说明 |
| 人物行动 | 写连续物理动作链 | 避免只写情绪形容词 |
| 台词/留白 | 标明要说的信息和必须保留的沉默 | 台词不解释画面已经成立的信息 |
| 声音/音乐 | 环境声、动作声、音乐、静默如何参与叙事 | 具体到声源 |
| 转场 | 说明场景之间的因果、情绪或视觉连接 | 不使用无意义硬切 |

## 三、景别选择规则

| 景别/构图 | 叙事用途 | 分镜写法 |
|---|---|---|
| 远景 | 让人物被空间吞没，背景可藏异常。 | 写入分镜表时标明叙事功能 |
| 中景 | 角色探索和空间变化的主力。 | 写入分镜表时标明叙事功能 |
| 近景 | 捕捉听见、意识到、想否认的瞬间。 | 写入分镜表时标明叙事功能 |
| 特写 | 用于旧物、门缝、手电、录音机、时钟等证据。 | 写入分镜表时标明叙事功能 |
| 负空间构图 | 留出异常可能出现的位置，让观众主动搜寻。 | 写入分镜表时标明叙事功能 |

### 景别执行原则

- 景别选择必须回答“观众此刻应该看见什么”：空间规则、人物关系、行动结果、情绪反应还是叙事证据。
- 同一场戏内景别变化要有方向，例如从远到近表示压力靠近，从近到远表示抽离或失去。
- 特写只给真正承担信息的物件、身体反应或关系证据；不要把所有漂亮细节都写成特写。
- 群像或多人场景必须标明主次关系，避免画面中所有角色同时抢戏。

## 四、运镜节奏规则

| 运镜 | 叙事用途 | 分镜写法 |
|---|---|---|
| 固定等待 | 让异常在观众注视中慢慢发生。 | 写明触发点和结束点 |
| 缓慢推进 | 表现不可避免的接近。 | 写明触发点和结束点 |
| 受限跟拍 | 限制视野，跟角色进入未知空间。 | 写明触发点和结束点 |
| 突然停住 | 暗示角色或环境察觉到某种存在。 | 写明触发点和结束点 |
| 克制揭示 | 看清异常后不要马上乱切，让恐惧被确认。 | 写明触发点和结束点 |

### 运镜执行原则

- 运镜开始点和结束点都要写清楚，例如“从门口缓推到角色握紧的手”，不能只写“镜头缓推”。
- 运镜速度服务信息释放：发现型可慢，危机型可快，决断型要稳。
- 快切段落要插入确认镜头，让观众知道位置、结果和代价。
- 关键反应、沉默、选择、揭示、和解、失败通常要减少花哨运镜。

## 五、时长把控

| 镜头类型 | 建议时长 | 叙事目的 |
|---|---|---|
| 正常建立 | 4-6 秒 | 让观众熟悉空间基准。 |
| 等待镜头 | 6-10 秒 | 让不安在画面中自然生成。 |
| 异常出现 | 0.5-2 秒 | 短促但必须可确认。 |
| 确认反应 | 3-5 秒 | 拍角色意识到规则变化。 |
| 余波停留 | 5-8 秒 | 让恐怖延伸到事件之后。 |

### 时长执行原则

- 时长不是固定公式，最终以观众能否读懂信息和感到情绪变化为准。
- 铺垫镜头必须让规则成立；落点镜头必须干净；反应和余波镜头必须让情绪被接住。
- 对白场景中，每次切换都应改变信息或关系；如果只是重复观点，应合并镜头。
- 无台词镜头需要更明确的身体动作、声源或空间变化，否则容易变成空镜堆砌。

## 六、人物行为与表演调度

| 编号 | 行为原则 | 分镜落点 |
|---|---|---|
| 1 | 恐惧必须有规则 | 观众可以暂时不知道规则，但事件不能随机；重复异常要逐步形成规律。 |
| 2 | 先破坏熟悉感 | 超自然恐怖最有效入口是日常空间中出现不合理细节。 |
| 3 | 等待比出现更重要 | 让观众有时间检查画面、怀疑声音、预想危险。 |
| 4 | 惊吓不能替代叙事 | 突发音效和突然出现只作为标点，核心是规则揭示和心理压迫。 |
| 5 | 安全表达 | 恐怖可以写不安、逃离、仪式感和心理压迫，避免露骨伤害细节或现实危险教学。 |

### 行为写法

- 用连续物理动作链替代抽象情绪：写“停在门口→手指松开门把→把话吞回去”，不要只写“很难过”。
- 每个动作都应带有目的：遮掩、靠近、试探、确认、逃避、承担、保护、放手。
- 人物反应要分层：当事人、旁观者、对立者和环境都可以有不同反应。
- 动作结果要可见，例如物件位置改变、关系距离改变、空间通路改变或声音状态改变。

## 七、台词、留白与声音

| 声音策略 | 叙事用途 | 分镜写法 |
|---|---|---|
| 环境底噪变化 | 电流、风、管道、远处低语逐步偏离正常。 | 写明声源、进入时机和退出时机 |
| 重复信号 | 同一敲击、铃声或童谣成为规则提示。 | 写明声源、进入时机和退出时机 |
| 音乐撤离 | 异常接近时减少配乐，让角色暴露在空间里。 | 写明声源、进入时机和退出时机 |
| 声音越界 | 声音从不可能的位置传来，提示空间规则被破坏。 | 写明声源、进入时机和退出时机 |
| 惊吓克制 | 突发声只用于关键转折，不能连续滥用。 | 写明声源、进入时机和退出时机 |

### 台词与留白

- 台词负责无法被画面直接看见的信息；画面已经成立的内容不要再让角色解释一遍。
- 留白必须有承接动作，例如看向别处、停止动作、声音消失、对方没有回应。
- 声音可以先于画面进入，也可以在关键时刻撤离；进入和撤离都要写入分镜表。
- 环境声、动作声、呼吸声和沉默应与配乐一样被规划，而不是后期随意补充。

## 八、转场设计

| 转场方式 | 使用方法 | 适用场景 |
|---|---|---|
| 动作接动作 | 用上一场未完成的动作进入下一场 | 适合保持因果连续 |
| 声音预入 | 下一场声音先进入当前画面 | 适合制造预兆、反差或时间跳转 |
| 物件回环 | 同一物件在不同段落改变意义 | 适合形成商业记忆点 |
| 空间对照 | 相似构图呈现关系或权力变化 | 适合表现成长、失去、和解或反转 |
| 情绪断切 | 从高压切到安静或从日常切到危机 | 必须让观众理解时间和地点变化 |

## 九、常见失败模式与修正

| 编号 | 失败模式 | 分镜修正方向 |
|---|---|---|
| 1 | 事件随机发生，没有可追踪的超自然规则。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 2 | 只靠突然音效和跳脸吓人，缺少等待与余波。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 3 | 异常过早解释清楚，神秘感被耗尽。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 4 | 恐怖点依赖露骨伤害细节或现实危险操作。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 5 | 空间关系混乱，观众不知道异常从哪里来。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |
| 6 | 画面阴暗但叙事没有信息差和规则递进。 | 在分镜表中增加目标、信息、行动、时长或反应镜头 |

## 十、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 可读性 | 只看分镜表也能理解人物目标、阻碍、信息差和状态变化。 |
| 可执行性 | 每个镜头都有景别、行动、时长、声音或转场依据。 |
| 类型性 | 镜头策略体现 `超自然恐怖`，而不是换标题仍可用于任意类型。 |
| 节奏 | 铺垫、转折、反应和余波均有明确时长或停顿规则。 |
| 人物 | 行为链具体，可由演员或生成模型执行。 |
| 边界 | 不引用具体 IP、导演、作品、品牌、平台或真实人物。 |
| 安全 | 不提供现实伤害、违法或危险行为的可操作步骤。 |
| 组合 | 可与任何视觉风格叠加，且不把美术风格写成叙事风格。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `超自然恐怖` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
