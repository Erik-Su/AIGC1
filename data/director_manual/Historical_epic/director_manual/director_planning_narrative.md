# 叙事手法 · 历史史诗 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `历史史诗` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 时代命题、权力秩序、个人选择、历史余波 |
| 离场感受 | 庄重、震荡、理解代价，感到个体被卷入更大进程 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 个人命运必须接入时代命题 | 主角不能旁观历史，要在忠诚、背叛、归属、牺牲中做选择。 | 需要落到人物行动、场景规则或镜头节奏 |
| 权力通过空间表现 | 台阶、座位、门廊、城墙、队列要体现秩序与压迫。 | 需要落到人物行动、场景规则或镜头节奏 |
| 大场面服务选择 | 战争、会盟、加冕、审判必须改变关系和局势，不做空洞奇观。 | 需要落到人物行动、场景规则或镜头节奏 |
| 群体不是背景 | 百姓、士兵、随从、见证者应体现历史影响面。 | 需要落到人物行动、场景规则或镜头节奏 |
| 结尾要有余波 | 展示选择之后世界如何改变，而非只结束在胜负。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 局部危机 | 从边境、家族、宫廷或民间事件切入时代裂缝 | 压抑、预兆 | 用小事件映射大局 |
| 阵营成形 | 人物被迫站队或隐藏立场 | 试探、权衡 | 每个选择都有可见代价 |
| 权力转向 | 联盟、背叛、战败或继承改变格局 | 沉重、不可逆 | 通过空间和仪式变化呈现 |
| 民间回响 | 普通人承受政策、战争或迁徙结果 | 现实、痛感 | 避免只拍权力中心 |
| 历史性决断 | 主角牺牲私人愿望或挑战旧秩序 | 庄严、高压 | 让镜头给判断时间 |
| 时代余波 | 旗帜、空座、废墟、迁徙、继任者显示新局 | 苍茫、回望 | 不把复杂历史简化成口号 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 会盟/朝会 | 用座位和发言顺序表现权力 | 礼制下的刀锋 | 每次发言必须改变局势 |
| 战前安静 | 人物在宏大事件前处理私人关系 | 克制、悬置 | 不要急着进入大战 |
| 攻防/迁徙 | 空间方位、目标、代价必须清楚 | 紧迫、沉重 | 避免无方向混战 |
| 审判/放逐 | 制度对个体施压 | 公开羞辱或庄严剥夺 | 拍见证者反应 |
| 归乡/废墟 | 历史结果进入生活空间 | 失落、辨认 | 让变化可见 |
| 继任/立誓 | 新秩序建立但带有阴影 | 庄重、复杂 | 避免单纯胜利姿态 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 群体声 | 脚步、祷告、呼喊、风中旗帜声承担时代尺度。 | 声音必须有可辨声源，不用抽象气氛词 |
| 仪式动机 | 鼓、号、钟、低弦用于秩序和命运感。 | 声音必须有可辨声源，不用抽象气氛词 |
| 战事留白 | 关键牺牲可撤掉音乐，只留风声或兵器落地。 | 声音必须有可辨声源，不用抽象气氛词 |
| 角色主题变形 | 同一旋律随立场变化转为冷硬或破碎。 | 声音必须有可辨声源，不用抽象气氛词 |
| 民间声音 | 市井、哭声、车轮、迁徙声让历史落地。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 大远景 | 建立城池、军阵、迁徙队伍和人物尺度。 | 景别选择要说明叙事理由 |
| 全景 | 显示礼制、队列、座次和群体结构。 | 景别选择要说明叙事理由 |
| 中景 | 承载谈判、誓言、背叛和阵营关系。 | 景别选择要说明叙事理由 |
| 近景 | 让宏大命题落到眼神、伤痕、沉默上。 | 景别选择要说明叙事理由 |
| 群体反应 | 让历史事件被见证，扩大叙事重量。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 缓慢推进 | 仪式和决断场面建立不可逆感。 | 运镜必须服务信息释放或人物状态变化 |
| 横移检阅 | 展示队列、军阵、宫廷秩序。 | 运镜必须服务信息释放或人物状态变化 |
| 克制正反打 | 谈判靠视线、站位和沉默推进。 | 运镜必须服务信息释放或人物状态变化 |
| 稳定长镜 | 重大选择前减少剪辑，放大责任。 | 运镜必须服务信息释放或人物状态变化 |
| 从个人拉至群体 | 结尾或余波提示命运进入历史层面。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 只有宏大口号，没有个人不可回避的选择。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 战争和仪式只是奇观，不改变权力格局。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 群体被当作背景贴图，没有见证和承受功能。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 方位混乱，观众看不懂战事目标和结果。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 历史被简化为单一善恶，缺少代价复杂度。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉宏大但导演叙事没有时代余波。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `历史史诗` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `历史史诗` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
