# 叙事手法 · 成长青春 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `成长青春` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 第一次经验、笨拙表达、时间不可逆、群像分离 |
| 离场感受 | 怀念、释然、微笑中泛泪，感到某个阶段真的结束了 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 成长来自具体第一次 | 不要写抽象成熟，要绑定第一次失败、告别、心动、承担责任。 | 需要落到人物行动、场景规则或镜头节奏 |
| 笨拙比完美更可信 | 说错话、逃避、逞强、迟到的道歉是青春情感的真实入口。 | 需要落到人物行动、场景规则或镜头节奏 |
| 时间感必须可见 | 用季节、考试表、校服变化、空教室、旧物磨损呈现不可逆。 | 需要落到人物行动、场景规则或镜头节奏 |
| 群像关系塑造主角 | 朋友、对手、老师、家人都应让主角看到不同版本的自己。 | 需要落到人物行动、场景规则或镜头节奏 |
| 高光不等于成功 | 成长高潮可以是失败后的承认、道歉、放手或重新选择。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 日常集体 | 建立熟悉的空间、玩笑、习惯和小目标 | 轻快、松散、鲜活 | 埋入即将改变的时间锚点 |
| 第一次触动 | 心动、竞赛、冲突或秘密让角色失衡 | 兴奋与慌张并存 | 不要让人物立刻说清感受 |
| 关系裂缝 | 朋友、家庭、理想或自我形象出现冲突 | 委屈、逞强、误解 | 通过行为躲避而不是长篇解释 |
| 试图证明 | 主角用幼稚方式争取认可或追回关系 | 急促、用力、带失败风险 | 动作要显示不成熟 |
| 真正承担 | 角色承认代价并主动修复或告别 | 安静、疼痛、清醒 | 让关键动作替代大道理 |
| 回望余韵 | 旧空间或旧物被重新看见 | 怀念、释然 | 留一处空位或未完成细节 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 课间/走廊/社团 | 用碎片动作建立群像默契 | 热闹中埋一个孤立者 | 避免纯校园符号堆叠 |
| 第一次心动 | 视线偷看、手指停顿、语速变乱 | 身体反应先于台词 | 不要直接用旁白宣布心动 |
| 友谊冷战 | 同空间不同框、擦肩不看、群聊沉默 | 距离变远 | 不能只靠争吵推动 |
| 比赛/考试/演出 | 外部目标压缩人物选择 | 热血与脆弱同场 | 胜负必须改变关系 |
| 毕业/搬离/分班 | 日常空间第一次失去日常感 | 热闹后突然安静 | 避免空泛煽情台词 |
| 多年后回望 | 旧物或旧地触发当下理解 | 时间重叠 | 回忆不要只是滤镜，要有新信息 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 空间声音 | 铃声、球场、教室翻书、走廊脚步成为时间标记。 | 声音必须有可辨声源，不用抽象气氛词 |
| 音乐记忆点 | 同一旋律在欢闹、失落、回望中做不同处理。 | 声音必须有可辨声源，不用抽象气氛词 |
| 突然安静 | 关系破裂或告别时让热闹环境退远。 | 声音必须有可辨声源，不用抽象气氛词 |
| 群体声浪 | 比赛和活动用人群声推动情绪，不只靠配乐。 | 声音必须有可辨声源，不用抽象气氛词 |
| 旧物声音 | 翻相册、拉拉链、粉笔落下等小声响承载回忆。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 群像全景 | 建立共同体，显示谁在中心、谁被边缘化。 | 景别选择要说明叙事理由 |
| 双人中景 | 适合朋友冷战、暗恋并肩、对手试探。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉笑容收住、眼眶泛红、逞强咬唇。 | 景别选择要说明叙事理由 |
| 大特写 | 给攥紧的试卷、未送出的纸条、空座位等青春证据。 | 景别选择要说明叙事理由 |
| 空镜 | 用走廊、操场、窗台记录时间流逝。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 手持微晃 | 日常群像有在场感，但不能影响信息可读。 | 运镜必须服务信息释放或人物状态变化 |
| 跟拍奔跑 | 表现追赶某人、赶赴比赛、逃离尴尬。 | 运镜必须服务信息释放或人物状态变化 |
| 缓推 | 用于发现某个情绪或意识到某个改变。 | 运镜必须服务信息释放或人物状态变化 |
| 缓拉 | 用于分离、毕业、角色从群体中退开。 | 运镜必须服务信息释放或人物状态变化 |
| 碎切蒙太奇 | 用于日常累积，必须有情绪递进而不是素材堆叠。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 把青春拍成只有滤镜和校服，没有成长选择。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 角色过度成熟，说出不符合年龄阶段的完整道理。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 只追求甜或燃，忽略失败、误解和告别的重量。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 群像角色没有功能，只作为背景热闹。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 时间流逝没有可见锚点，情绪变化显得突然。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉风格青春化，但镜头没有第一次经验和不可逆时间感。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `成长青春` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `成长青春` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
