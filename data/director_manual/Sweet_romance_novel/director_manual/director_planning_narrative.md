# 叙事手法 · 甜宠言情 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `甜宠言情` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 双向选择、细节照顾、关系升温、尊重边界 |
| 离场感受 | 被理解、被坚定选择，心里发甜但不腻 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 甜来自被看见 | 角色记住偏好、发现疲惫、替对方留空间，比夸张宠溺更有效。 | 需要落到人物行动、场景规则或镜头节奏 |
| 关系必须双向 | 双方都要做选择、承担风险、修正误解。 | 需要落到人物行动、场景规则或镜头节奏 |
| 心动要有阶段 | 陌生、试探、熟悉、动摇、退缩、确认应有可见变化。 | 需要落到人物行动、场景规则或镜头节奏 |
| 冲突保持尊重 | 误会和拉扯不能依赖羞辱、强迫、控制或越界。 | 需要落到人物行动、场景规则或镜头节奏 |
| 甜点后要有反应 | 递伞、靠近、解围之后要拍被照顾者如何接收。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 关系入口 | 一次错位、合作或互补需求让两人绑定 | 轻松、好奇 | 建立差异而非立刻相爱 |
| 试探熟悉 | 通过小任务和日常互动积累默契 | 轻甜、躲闪 | 甜点要改变距离 |
| 情感确认前退缩 | 秘密、事业、家庭或自尊让角色后退 | 酸涩、误解 | 保留双方动机 |
| 主动修复 | 一方或双方用行动澄清误会 | 紧张、真诚 | 不能只靠偶然听见真相 |
| 公开选择 | 角色在外部压力下选择关系 | 坚定、温暖 | 选择要有代价 |
| 未来姿态 | 关系进入共同生活或共同目标 | 安心、持续 | 结尾不是占有，而是同行 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 偶遇/同路 | 距离从陌生到并肩 | 轻微尴尬 | 不要一上来过度亲密 |
| 递伞/留灯/带饭 | 具体照顾动作表达关注 | 被看见 | 动作要符合人物性格 |
| 共同任务 | 合作中发现彼此能力和弱点 | 默契升温 | 任务必须有真实压力 |
| 误会错过 | 消息未发出、话被打断、位置错开 | 酸涩、着急 | 误会不能拖到消耗耐心 |
| 告白前夜 | 人物先面对自己真实需求 | 安静、期待 | 不要只堆浪漫景物 |
| 关系确认 | 双人同框稳定，距离自然靠近 | 温暖、确定 | 避免强迫式占有表达 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 小声响放大 | 杯子轻碰、短信提示、雨声、钥匙声制造亲密。 | 声音必须有可辨声源，不用抽象气氛词 |
| 主题旋律递进 | 从轻微动机到确认关系时完整出现。 | 声音必须有可辨声源，不用抽象气氛词 |
| 误会收窄 | 减少音乐，让停顿和环境声承载酸涩。 | 声音必须有可辨声源，不用抽象气氛词 |
| 环境温度 | 咖啡馆、雨夜、厨房、街口声音参与关系氛围。 | 声音必须有可辨声源，不用抽象气氛词 |
| 不过度甜化 | 避免全程糖水音乐导致疲劳。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 双人中景 | 显示距离、并肩、错身和站位变化。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉眼神回避、忍笑、欲言又止。 | 景别选择要说明叙事理由 |
| 手部特写 | 递物、牵手前停顿、消息删除等情感证据。 | 景别选择要说明叙事理由 |
| 环境见证 | 走廊、窗边、餐桌、车站作为关系阶段容器。 | 景别选择要说明叙事理由 |
| 单人留白 | 退缩或等待时表现内心距离。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 轻柔跟移 | 日常并肩和共同任务保持舒适节奏。 | 运镜必须服务信息释放或人物状态变化 |
| 缓慢推近 | 心动或理解发生时使用。 | 运镜必须服务信息释放或人物状态变化 |
| 固定隔断 | 误会段用门、桌、玻璃表现无法靠近。 | 运镜必须服务信息释放或人物状态变化 |
| 从单人到双人 | 和解后镜头让两人重新进入同框。 | 运镜必须服务信息释放或人物状态变化 |
| 少用花哨运动 | 告白和确认把注意力留给人物。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 甜宠变成单向控制或无边界占有。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 两人关系没有阶段变化，只是不断发糖。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 误会拖沓且靠不沟通维持，降低人物可信度。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 甜点动作与人物性格无关，像清单堆砌。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 冲突用羞辱或强迫制造张力。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉浪漫但没有双向选择和细节照顾。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `甜宠言情` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `甜宠言情` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
