# 叙事手法 · 都市职场剧 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `都市职场剧` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 任务压力、权力结构、专业细节、个人边界 |
| 离场感受 | 清醒、现实、看到一个人在系统中守住自我 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 任务是叙事发动机 | 每场戏都要服务项目、客户、危机、汇报、交付或职业选择。 | 需要落到人物行动、场景规则或镜头节奏 |
| 权力关系要可视化 | 座位、发言顺序、谁站谁坐、谁掌握屏幕体现结构。 | 需要落到人物行动、场景规则或镜头节奏 |
| 专业细节必须改变局势 | 文件、数据、时间表、合同不是摆设，要触发决策。 | 需要落到人物行动、场景规则或镜头节奏 |
| 胜利带代价 | 职场爽点必须伴随关系、健康、信任或价值观成本。 | 需要落到人物行动、场景规则或镜头节奏 |
| 工作与生活互相挤压 | 个人边界、家庭、感情、身体疲惫要进入职业选择。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 明确任务 | 项目目标、期限、利益相关方出场 | 高效、压力初现 | 指标和风险要具体 |
| 信息不对称 | 有人隐瞒、误判、甩锅或抢功 | 紧绷、试探 | 让观众知道谁握有关键牌 |
| 危机升级 | 客户变更、舆情、系统故障、预算压缩 | 倒计时、混乱 | 每次升级改变行动方案 |
| 团队裂缝 | 成员目标不同但必须协作 | 冲突、疲惫 | 不同立场都有现实理由 |
| 公开选择 | 汇报、谈判、发布或问责现场 | 高压、清醒 | 主角做出职业伦理选择 |
| 结果余波 | 项目结果反作用于关系和自我认知 | 疲惫、现实 | 不把加班胜利拍成唯一答案 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 会议室 | 权力、信息、责任转移集中发生 | 克制博弈 | 避免纯台词转述 |
| 深夜工位 | 效率背后的消耗可视化 | 疲惫、孤独 | 用细节表现而非喊累 |
| 茶水间/电梯 | 非正式信息流动 | 压低声音的真实 | 对话要改变联盟 |
| 客户现场 | 专业能力和临场判断受考验 | 紧张、表面礼貌 | 客户不是脸谱化障碍 |
| 屏幕/文件交接 | 证据、权限、版本差异推动剧情 | 冷静、关键 | 信息需可读 |
| 下班生活侵入 | 电话、消息、突发任务打破私人空间 | 边界被压缩 | 避免把牺牲私生活美化成唯一正确 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 办公音景 | 键盘、通知、打印、电梯、空调形成压力背景。 | 声音必须有可辨声源，不用抽象气氛词 |
| 倒计时节奏 | 音乐随任务迫近收紧，但不遮盖关键信息。 | 声音必须有可辨声源，不用抽象气氛词 |
| 谈判留白 | 重要场合让呼吸、翻纸、杯子声参与压力。 | 声音必须有可辨声源，不用抽象气氛词 |
| 城市噪音 | 下班路、交通、电话提示表现系统无处不在。 | 声音必须有可辨声源，不用抽象气氛词 |
| 危机后安静 | 结果出来后保留疲惫，而非马上胜利配乐。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 会议全景 | 展示座位、阵营、谁被孤立。 | 景别选择要说明叙事理由 |
| 双人中景 | 适合交换条件、试探、私下联盟。 | 景别选择要说明叙事理由 |
| 屏幕特写 | 用于证据、时间、版本、签字和权限变化。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉公开压力下的微表情和克制。 | 景别选择要说明叙事理由 |
| 城市远景 | 对照个体努力与庞大系统。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 干练跟拍 | 项目推进和跨部门奔走。 | 运镜必须服务信息释放或人物状态变化 |
| 克制正反打 | 权力博弈让视线承担张力。 | 运镜必须服务信息释放或人物状态变化 |
| 轻微滞后 | 角色疲惫时镜头跟不上，表现压力追赶。 | 运镜必须服务信息释放或人物状态变化 |
| 稳定长看 | 问责或选择时减少切换。 | 运镜必须服务信息释放或人物状态变化 |
| 交叉剪辑 | 多个团队同步处理同一危机。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 会议戏全靠台词说明，没有权力站位和信息动作。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 专业细节只是背景，不改变决策。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 职场胜利被拍成无代价爽文。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 角色生活完全缺席，压力没有现实重量。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 反派脸谱化，缺少组织结构和利益逻辑。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉现代但叙事没有任务链和职业伦理选择。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `都市职场剧` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `都市职场剧` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
