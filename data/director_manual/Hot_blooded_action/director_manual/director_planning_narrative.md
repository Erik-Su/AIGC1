# 叙事手法 · 热血动作 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `热血动作` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 目标清晰、动作因果、升级节拍、信念爆发 |
| 离场感受 | 振奋、痛快、相信角色配得上胜利或失败后的再起 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 动作服务目标 | 每场动作戏必须明确角色想抢什么、救谁、阻止什么或证明什么。 | 需要落到人物行动、场景规则或镜头节奏 |
| 招式有因果 | 试探、受挫、调整、反击、代价要能被看懂。 | 需要落到人物行动、场景规则或镜头节奏 |
| 热血来自选择 | 爆发不是喊口号，而是在明知代价时继续行动。 | 需要落到人物行动、场景规则或镜头节奏 |
| 空间方位优先 | 快节奏也要让观众知道角色位置、路线和危险来源。 | 需要落到人物行动、场景规则或镜头节奏 |
| 胜利必须有代价 | 体力、关系、机会或伤痛的代价让动作成果可信。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 目标亮明 | 用明确任务建立行动方向 | 紧迫、直接 | 目标必须可拍到 |
| 能力差距 | 对手、环境或规则压制主角 | 受挫、压力 | 让失败暴露缺口 |
| 训练/协作 | 角色通过学习、信任或策略补足缺口 | 积累、准备 | 训练不能只是蒙太奇，要改变战法 |
| 连续升级 | 阻碍从体力、空间、心理多层加压 | 加速、拉满 | 每次升级改变局势 |
| 信念爆发 | 角色在代价中做出选择 | 燃点、专注 | 爆发要有前文铺垫 |
| 胜负余波 | 胜利或失败改变关系和下一步任务 | 释放、反思 | 不要打完就结束 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 追逐 | 路线、障碍、目标物清楚 | 速度与选择 | 避免无意义奔跑 |
| 训练 | 动作重复中看到缺点和修正 | 汗水、挫败、进步 | 不能只有酷炫动作 |
| 团队配合 | 不同能力互补完成同一目标 | 信任形成 | 每个队友要有功能 |
| 一对一决斗 | 通过战法变化表现心理变化 | 压迫、反击 | 不要只堆招式 |
| 守护/救援 | 动作与情感目标合一 | 焦急、牺牲 | 空间路线要明确 |
| 失败后再起 | 角色承认弱点并换策略 | 疼痛、重新站起 | 避免无铺垫开挂 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 节奏鼓点 | 随动作升级增强，但不遮盖关键声源。 | 声音必须有可辨声源，不用抽象气氛词 |
| 身体声 | 喘息、脚步、衣料、碰撞让代价具体。 | 声音必须有可辨声源，不用抽象气氛词 |
| 短暂停音 | 重大冲击或信念爆发前制造真空。 | 声音必须有可辨声源，不用抽象气氛词 |
| 团队呼应 | 呼喊、提示、接力声体现协作。 | 声音必须有可辨声源，不用抽象气氛词 |
| 胜负余音 | 打完后的安静比持续燃乐更有重量。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 全景 | 建立动作空间、路线、敌我位置。 | 景别选择要说明叙事理由 |
| 中景 | 表现招式起止和身体力量。 | 景别选择要说明叙事理由 |
| 近景 | 捕捉受伤、咬牙、判断和意志转变。 | 景别选择要说明叙事理由 |
| 特写 | 用于目标物、脚步、握拳、破绽。 | 景别选择要说明叙事理由 |
| 主观镜头 | 短暂进入角色判断，不可过度影响方位。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 跟拍 | 追随行动路线，保持目标和障碍可见。 | 运镜必须服务信息释放或人物状态变化 |
| 横移 | 展示双方距离变化和攻防层次。 | 运镜必须服务信息释放或人物状态变化 |
| 快速推近 | 放大决心、破绽或冲击落点。 | 运镜必须服务信息释放或人物状态变化 |
| 慢动作 | 只用于选择、牺牲、逆转瞬间。 | 运镜必须服务信息释放或人物状态变化 |
| 稳定回看 | 动作完成后让结果被确认。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 动作很炫但目标不清，观众不知道为何而战。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 连续快切导致方位和结果不可读。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 主角无铺垫突然变强，破坏成长可信度。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 团队成员没有功能，只在旁边喊加油。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 暴力细节过度，偏离热血动作的商业边界。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉动感强但缺少信念选择和代价余波。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `热血动作` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `热血动作` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
