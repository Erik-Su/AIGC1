# 叙事手法 · 心理剧情 · 商用导演规划手册

## 一、商业定位

本手册用于在剧本进入导演规划阶段时，将 `心理剧情` 的叙事规律转化为可执行的主题、段落、场景、声音、构图和镜头策略。它不是美术风格手册，不规定画面材质、线条或色彩；它负责判断故事如何讲、信息何时释放、人物如何行动、镜头为什么这样组织。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 内外冲突、主观偏差、压抑行为、认知转变 |
| 离场感受 | 复杂、刺痛、理解人物为什么无法轻易说出口 |
| 输出对象 | 导演规划、分场景意图、分镜表前置策略、视频镜头说明 |
| 适配范围 | 可与写实、动画、漫画、水墨、3D、像素、定格等任意视觉风格组合 |
| 禁止替代 | 不用视觉风格替代叙事判断，不用抽象情绪词替代可拍行动 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 心理必须外化为行为 | 焦虑、羞耻、执念要通过手势、站位、回避、重复动作呈现。 | 需要落到人物行动、场景规则或镜头节奏 |
| 主观不等于混乱 | 可以扭曲时间和空间，但观众要知道这是人物感知而非剪辑错误。 | 需要落到人物行动、场景规则或镜头节奏 |
| 关系是压力源 | 心理变化通常来自亲密关系、权力关系或自我评价被触发。 | 需要落到人物行动、场景规则或镜头节奏 |
| 沉默有结构 | 沉默前后必须有信息变化，不是简单拖慢节奏。 | 需要落到人物行动、场景规则或镜头节奏 |
| 转变要付代价 | 人物的清醒、承认或离开都要改变现实关系。 | 需要落到人物行动、场景规则或镜头节奏 |

### 主题写法

- 主题必须落在角色的可见选择上，例如“是否承认错误”“是否守住承诺”“是否公开真相”，避免只写“关于爱与成长”这类空泛判断。
- 情感主线拆成 2-3 个递进阶段，每个阶段对应一种可拍变化：站位变近或变远、行动从逃避到承担、声音从嘈杂到安静、空间从封闭到打开。
- 对立力量不能只是“坏人”或“困难”，应代表一种与主角价值相冲突的规则、欲望、误解或制度。
- 结尾必须回应开头埋下的欲望、缺口、誓言、秘密或关系债，让观众感到叙事闭合。

## 三、叙事结构与节奏模型

| 段落 | 叙事功能 | 情绪/压力方向 | 导演控制点 |
|---|---|---|---|
| 表面稳定 | 角色维持功能性外壳 | 克制、正常 | 埋入重复动作或回避点 |
| 触发事件 | 一句话、旧物、相遇或失败击中内在伤口 | 微裂、失衡 | 不要立刻解释创伤 |
| 压抑升级 | 角色用控制、否认、讨好或逃避维持秩序 | 紧绷、窒息 | 让行为越来越耗费体力 |
| 主观错位 | 记忆、想象、现实交叠 | 不可靠、破碎 | 保留可追踪锚点 |
| 对峙自我 | 角色无法再维持旧解释 | 暴露、痛感 | 对峙可以安静而非爆发 |
| 有限改变 | 人物做出一个现实行动 | 清醒、不完美 | 不要让一次顿悟解决全部问题 |

### 节奏控制

- 每个段落必须回答：角色此刻想要什么、谁或什么阻碍了他、观众比角色多知道还是少知道什么。
- 节奏的“快”指信息密度和行动压力提高，不等于无意义缩短所有镜头。
- 节奏的“慢”必须让关系、线索、空间或选择发生变化，不能只是气氛拖延。
- 关键转折前要给观众建立预期，转折后要给人物留下反应和后果。

## 四、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 封闭房间 | 空间压迫内心 | 呼吸变窄 | 构图不能只追求压抑而无行为 |
| 亲密对话 | 最熟悉的人说出最刺痛的信息 | 克制冲突 | 让停顿比台词更重要 |
| 重复日常 | 同一动作重复到变形 | 控制与崩裂 | 重复要逐次变化 |
| 记忆闪回 | 过去以碎片进入当下 | 刺点、失真 | 用声源或物件做锚点 |
| 公共场合失控 | 外在秩序与内在崩裂对照 | 羞耻、暴露 | 避免夸张表演 |
| 独处决定 | 角色终于做出一个小而真实的行动 | 安静、清醒 | 结尾不必完全治愈 |

### 分场景写作要求

- 每场戏先写“这场戏改变了什么”，再写画面和台词。
- 场景中的道具、空间、声音或动作至少有一个承担叙事证据功能。
- 如果场景只提供氛围、世界观或美术展示，但不改变人物关系和信息状态，应删除或合并。
- 同类场景反复出现时，第二次和第三次必须改变权力关系、情绪含义或人物选择。

## 五、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 身体声放大 | 呼吸、吞咽、衣料、笔尖摩擦表现内压。 | 声音必须有可辨声源，不用抽象气氛词 |
| 环境声失衡 | 公共噪音忽远忽近，表现主观收缩。 | 声音必须有可辨声源，不用抽象气氛词 |
| 记忆声源 | 某个旧声音触发回忆，不用解释性旁白。 | 声音必须有可辨声源，不用抽象气氛词 |
| 配乐稀疏 | 心理剧情不宜全程铺情绪，保留真实沉默。 | 声音必须有可辨声源，不用抽象气氛词 |
| 突然真实 | 主观段落后回到清晰环境声，确认现实。 | 声音必须有可辨声源，不用抽象气氛词 |

### 声音规划原则

- 声音描述必须具体到声源，例如脚步、门锁、雨声、呼吸、键盘、风、铃、远处人群，避免只写“紧张音乐”或“温暖氛围”。
- 配乐覆盖率建议控制在 40%-70% 之间；关键选择、沉默、揭示或真情段落优先考虑撤掉配乐。
- 同一声音元素可以作为回环锚点，但每次出现都要改变含义。
- 音乐进入和退出要有叙事理由：预兆、反差、释放、余波或情绪遮断。

## 六、构图与景别叙事

| 景别/构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 近景 | 观察微表情和控制失败的瞬间。 | 景别选择要说明叙事理由 |
| 特写 | 手、喉结、眼睑、反复触摸的物件。 | 景别选择要说明叙事理由 |
| 框中框 | 表现自我囚禁、窥视或关系距离。 | 景别选择要说明叙事理由 |
| 偏侧留白 | 呈现人物心理缺口和未说出口的对象。 | 景别选择要说明叙事理由 |
| 主观视角 | 短暂表现感知偏差，需与现实镜头区分。 | 景别选择要说明叙事理由 |

### 构图控制

- 全景和远景负责空间规则、人物尺度和关系格局；近景和特写负责选择、反应和证据。
- 前景、中景、背景至少有两层承担信息功能，避免只做装饰性纵深。
- 遮挡、门框、座位、台阶、窗户、走廊、桌面、道具位置都可以成为关系和信息边界。
- 构图变化应服务人物关系变化，例如从分隔到同框、从压迫到开放、从混乱到秩序。

## 七、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 缓慢推近 | 逼近人物无法回避的内心。 | 运镜必须服务信息释放或人物状态变化 |
| 微弱晃动 | 表现主观不稳定，但不要变成惊悚手法。 | 运镜必须服务信息释放或人物状态变化 |
| 固定长看 | 让观众承担尴尬和压迫。 | 运镜必须服务信息释放或人物状态变化 |
| 反常角度 | 用于心理错位，必须有触发原因。 | 运镜必须服务信息释放或人物状态变化 |
| 缓拉疏离 | 关系断裂或自我抽离时使用。 | 运镜必须服务信息释放或人物状态变化 |

### 运镜控制

- 默认先判断是否需要移动镜头；如果固定机位已经能让行动和信息成立，不要为了“高级感”移动。
- 运镜要写明原因，例如“缓推=角色意识到真相”“横移=展示阵营关系”“跟拍=压缩路线压力”。
- 高潮段可以提高运动强度，但不能牺牲空间方向、行动起止和信息清晰度。
- 重要选择、揭示、和解、失去、告别通常需要减少运镜，让人物行为承担重量。

## 八、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 大量抽象心理描述，没有可拍动作。 | 改为具体动作、规则、信息边界或镜头证据 |
| 2 | 主观剪辑过乱，观众无法区分现实和感知。 | 改为具体动作、规则、信息边界或镜头证据 |
| 3 | 人物突然顿悟，缺少行为代价。 | 改为具体动作、规则、信息边界或镜头证据 |
| 4 | 沉默只是拖时长，不改变信息或关系。 | 改为具体动作、规则、信息边界或镜头证据 |
| 5 | 把心理痛苦拍成猎奇奇观。 | 改为具体动作、规则、信息边界或镜头证据 |
| 6 | 视觉压抑但缺少内外冲突递进。 | 改为具体动作、规则、信息边界或镜头证据 |

## 九、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 主题 | 一句话能说清 `心理剧情` 的核心命题，且不依赖视觉风格。 |
| 人物 | 主角目标、弱点、阻碍、选择和代价均可拍成行动。 |
| 结构 | 段落之间存在因果递进，不靠随机事件或旁白硬转。 |
| 场景 | 每个典型场景都承担关系变化、信息揭示或价值选择。 |
| 声音 | 音乐、环境声和沉默均有叙事功能，而非泛化氛围。 |
| 镜头 | 景别和运镜能解释为什么此刻这样拍。 |
| 边界 | 不引用具体导演、作品、角色、品牌、平台或可识别 IP。 |
| 商用 | 可交给编剧、导演、分镜师和视频生成流程直接执行。 |

## 附录：与视觉风格的组合规则

- 本手册只定义 `心理剧情` 的故事讲述、信息释放、人物行动、声音策略和镜头叙事，不绑定任何固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；导演手册负责“为什么这样讲、何时揭示、角色如何行动”。
- 当视觉风格与叙事情绪冲突时，优先保持人物目标、因果逻辑和信息边界成立，再调整画面表现。
- 生成导演规划、分镜表或视频镜头前，应先读取本叙事手册，再叠加 `data/skills/art_list` 中的艺术风格手册。
